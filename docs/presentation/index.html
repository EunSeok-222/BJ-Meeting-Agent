01 · Background

프로젝트 배경

🗣️ 문제 상황

"북잡(Bookjob)" 팀은 매주 여러 차례 디스코드 음성 회의를 진행하지만, 회의가 끝난 뒤 누군가 녹음을 다시 들으며 회의록을 정리해야 했습니다. 1~2시간짜리 회의를 요약하는 데 드는 시간과, 회의 중 섞인 사담·잡담을 걸러내는 수작업이 팀 생산성을 갉아먹었습니다.

🎯 목표

  • 회의 종료와 동시에 핵심 액션 플랜만 남긴 요약본 자동 생성
  • 사담·인사말은 걸러내고 회의 내용만 추출
  • 결과를 팀이 이미 쓰는 노션 데이터베이스에 바로 기록
  • 참석 인원 기반으로 전체/프론트/백엔드 회의 자동 분류
02 · Features

주요 기능

🎙️ 음성 수집·병합

디스코드 음성 채널의 유저별 PCM 스트림을 저장 후 자동 병합

📦 오디오 압축

FFmpeg로 대용량 오디오를 MP3(64kbps)로 압축해 업로드 최적화

🧠 Gemini 요약

100만 토큰급 컨텍스트로 1~2시간 회의도 한 번에 요약

🧹 사담 필터링

프롬프트 엔지니어링으로 인사·잡담 제외, 미참석자 자동 제외

📝 노션 자동 기록

볼드·헤딩·리스트·표를 블록 단위로 변환해 노션에 업로드

👥 참석자 매핑

디스코드 참여자를 노션 사용자(Attendees)에 자동 연결

08 · Retrospective

배운 점 & 성과

✅ 성과

  • 회의 종료 → 노션 기록까지 완전 자동화
  • 회의록 정리 인력·시간 부담 제거
  • 참석 인원 기반 카테고리 자동 분류로 팀별 회의록 정리

💡 배운 점

  • 외부 API(디스코드·Gemini·노션) 각각의 제약을 먼저 파악하는 게 설계 시간을 아낀다
  • 대용량 파일은 서버를 거치지 않는 경로(클라우드 업로드)가 안정적
  • SDK 메이저 업데이트는 저수준 API로 우회할 수 있는 여지를 늘 열어둔다

음성 → AI 요약 → 협업 도구 연결로 팀의 반복 업무를 줄이는 방향으로 발전
